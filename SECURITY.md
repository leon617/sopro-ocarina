# Política de segurança

Não publique vulnerabilidades, arquivos maliciosos de demonstração, tokens ou dados pessoais em issues públicas.

Ao relatar uma falha, informe a versão, o navegador, o formato do arquivo e passos mínimos para reproduzir. Remova partituras privadas do exemplo. Use o recurso **Security advisories** do GitHub para comunicação privada com os responsáveis pelo repositório.

Recebem prioridade falhas no parser XML/MXL/MIDI, descompressão, validação de URLs, SSRF, redirecionamentos, cache e exposição de dados armazenados no dispositivo.

Somente a versão mais recente publicada recebe correções de segurança.
